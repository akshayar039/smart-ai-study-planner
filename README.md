# Smart AI Study Planner

A Python and Flask-based study planner designed to help students organize their study schedules and track their learning progress.

## Features
- Personalized study planning
- Study plan management
- Progress tracking
- Web-based user interface

## Technologies Used
- Python
- Flask
- HTML and CSS

## Installation and Setup

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Navigate to the project folder:
   ```bash
   cd smart-ai-study-planner
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   python main.py
   ```

5. Open the local URL shown in your terminal in your browser.
